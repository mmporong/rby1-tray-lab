# 60 FPS 물리 기록과 RGB·깊이 모니터

소스 `c7967a9aab6a31fafc574150d959c36477f9cf59`, 기본 이동형 설정의 별도 물리 실행이다. 151.232초에 파지·상승·안착·해제·회수·기본 자세 복귀를 통과했다.

전체·파지·안착 시점은 각각 960×720, H.264, 60 FPS, 1,136프레임이다. 18.933초 영상의 표시 1배속이 물리 8배속에 대응하며 1.5배속과 2배속도 지원한다. 물리 계산은 2 ms를 유지한다.

[load.mp4](load.mp4)는 같은 시각의 관절 토크/모델 제한 비율을 링크 색으로 표시한다. 1,136개 기록 표본과 별도 재실행의 관절 위치·토크, 베이스, 트레이, 적재물 위치·속도를 대조한 최대 차이는 0이었다. 적재물 회전은 원본 표본에 없어 대조하지 않았다. 물리 소스와 시각화 스크립트 SHA는 `manifest.json`의 `supplementary_visualizations`에 구분한다. 구조 응력·변형·파손이나 하드웨어 정격을 뜻하지 않는다.

`sensors.json`은 제어 관측 7개와 별도 1 Hz 모니터 관측 456개의 RGB·깊이 PNG 경로, 시각, 역할, 공통 배치를 연결한다. 완전한 세 카메라 배치의 최신 과거 관측만 6패널에 표시한다. 깊이 범위는 머리 0.1–8 m, 손목 0.07–0.50 m이며 유효하지 않은 깊이는 자홍색이다. metric 원본은 같은 소스의 `evidence/mobile-native/controller-data`에 있다.

`manifest.json`은 설정·소스·모든 재생 산출물의 해시를 고정한다. `browser-qa.json`은 실제 브라우저에서 재생, 배율, 카메라 확대, 시점 변경, 모바일, 초기화와 종료 상태를 확인한 기록이다.
