# 기본 자세 출발·복귀 기록 재생

기본 표시 1배속은 시뮬레이션 8배속이다. 1·1.5·2배속은 영상의 native playback rate 1·1.5·2이며 물리 시각으로는 8·12·16배다.

| 항목 | 기록 |
|---|---|
| 소스 | `4963881fe6dc27aa9f7ef741721ec0fdef038cd2`, 기록 당시 작업 트리 변경 없음 |
| 물리·제어 | 2 ms 유지 |
| 전체 작업 | 140.246초, 모델 기본 자세 출발·안착·후진·기본 자세 복귀, 6개 조건 성공 |
| 영상 | 전체·파지·안착 3시점, 960×720, H.264/yuv420p, 60 FPS, 각 1,053프레임 |
| 기본 1배속 길이 | 17.550초 |
| 상태 | 영상 프레임 i의 i×8/60초 최근접 실제 물리 상태와 마지막 성공 상태 |
| RGB-D | 같은 재생 실행의 머리 1회·양손목 각 2회, 미래 관측 표시 안 함 |

첫 프레임은 모델 `qpos0`의 상체·헤드·그리퍼 자세다. 낮은 작업 자세를 준비한 뒤 트레이를 운반하고, 손 회수 후 후진해 초기 위치로 돌아온 다음 기본 자세를 복구한다. `withdrawn`만으로 영상이 끝나지 않고 `returned_home`에서 종료한다.

모든 프레임은 실제 MuJoCo 적분 상태의 렌더다. 물리 스텝을 건너뛰거나 영상 보간으로 움직임을 만들지 않았다. 화면 배율은 기록 재생률이며 CPU에서 물리를 실시간 8–16배 계산한다는 의미가 아니다.

`manifest.json`은 소스·설정·17개 원본 산출물의 SHA-256을 기록한다. `states.json.gz`는 같은 프레임의 실제 상태이고 `sensors.json`은 RGB/depth 표시용 PNG를 연결한다. 미터 단위 원본 깊이와 전체 500 Hz 명령·센서 계약은 같은 소스·설정으로 별도 실행한 `evidence/mobile-native`에 있다.

`browser-qa.json`은 이 재생 묶음의 브라우저·HTTP·영상 검증을 기록한다. 원본 60 FPS·프레임 수·전체 디코딩을 검사한다. 브라우저 프레임 유실 카운터는 검사 인터페이스에서 제공되지 않으므로 실측값으로 보고하지 않는다. 실물 실행은 검증 범위에 포함되지 않는다.
