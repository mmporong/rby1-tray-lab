# 부드러운 기록 재생

기본 표시 **1배속은 이전 시뮬레이션 8배속**이다. 1·1.5·2배속 선택은 같은 영상의 native playback rate 1·1.5·2를 사용하며, 시뮬레이션 시각으로는 8·12·16배에 해당한다.

| 항목 | 기록 |
|---|---|
| 물리 실행 소스 | `9f9fd5590b267b63d268f17ddf95f6d8b0507de8`, 작업 트리 변경 없음 |
| 물리/제어 간격 | 기존 2 ms 유지 |
| 전체 작업 | 102.470초, 파지·상승·안착·해제·회수 성공 |
| 영상 | 전체·파지·안착 3시점, 960×720, H.264/yuv420p, 60 FPS, 각 770프레임 |
| 기본 1배속 영상 길이 | 12.833초 |
| 상태 정렬 | 영상 프레임 i에 대해 시뮬레이션 i×8/60초의 최근접 물리 상태, 마지막 성공 상태 포함 |
| 센서 | 같은 실행에서 기록한 머리 1·양손목 각 2프레임, 재생 시각 이전의 최신 관측만 제공 |

기립 경유점이 제거된 낮은 자세의 픽업 경로를 기록했다. 파지 전 머리의 베이스 기준 최고 높이는 약 0.918 m다.

실제 MuJoCo 실행 상태를 렌더링해 기록했다. 물리 스텝을 건너뛰거나 영상 보간으로 움직임을 생성하지 않았다. CPU에서 물리를 실시간 8–16배로 계산한다는 주장은 하지 않는다. 화면의 배율을 바꿔도 기록된 관절·접촉·제어 실행 결과는 바뀌지 않는다.

`manifest.json`은 실행 소스·설정·17개 원본 산출물의 SHA-256을 기록한다. `states.json.gz`는 영상별 같은 프레임 인덱스에 대응하는 실제 snapshot이다. `sensors.json`은 RGB/depth 표시용 PNG와 관측 시각을 연결한다. PNG는 metric depth 원본이 아니며, 실물 전이 데이터 계약과 NPZ 원본은 기존 `evidence/mobile-native`에 있다.

`browser-qa.json`은 새 묶음의 HTTP 제공·영상·상태 검사와 이전 UI 검증의 출처를 구분한다. 새 묶음 교체 후에는 브라우저 연결이 끊겨 화면 재생을 재검증하지 못했다. 서버에서 새 소스의 재생 묶음과 표시 1·1.5·2배속 설정이 제공되는 것은 확인했다.

원본 영상의 60 FPS·프레임 수·전체 디코딩을 검사했다. 브라우저 프레임 유실 카운터는 검사 인터페이스에서 제공되지 않아 실측값으로 보고하지 않는다.
