# 모델링 범위와 근거

이 프로젝트는 Google DeepMind MuJoCo Menagerie의 `RBY1-A 1.2` 모델을 사용한다. 실행할 때 Menagerie 저장소를 별도 캐시에 받고 커밋 `cda5236f98383f6fbaa4820c6b18dba892cd087f`로 고정한다. 원본 라이선스는 Apache-2.0이다. 로더는 커밋, `origin` URL, 라이선스 문구, Git 작업 트리 상태를 검사하며 모델 XML과 메시 파일의 SHA-256을 실행 산출물에 남긴다. 캐시 파일이 수정됐거나 추적되지 않은 파일이 생기면 실행을 중단한다.

## 어디까지 검증하는가

RB-Y1 차체는 월드에 고정했다. 원본의 `world_j` 자유 관절을 제거한 방식이며 트레이나 적재물에는 weld 또는 mocap을 쓰지 않는다. 따라서 이 실험으로 검증하는 대상은 고정 지그 위 상체의 양팔 파지, 운반, 안착이다. 바퀴 주행, 균형 제어, 전도 안정성은 결과 범위에 포함하지 않는다.

관측값은 MuJoCo의 상태와 접촉력이다. 센서 노이즈, 카메라 인식 오차, 통신 지연은 모델에 들어 있지 않다. 위치 액추에이터의 게인과 힘 제한도 Menagerie가 제공한 시뮬레이션 파라미터를 유지한다. 실제 RB-Y1의 캘리브레이션 값이나 하드웨어 성능으로 해석할 수 없다.

바닥에 놓인 트레이를 위에서 파지할 수 있도록 높이 120 mm의 측면 손잡이를 합성했다. 트레이 크기와 질량, 적재물 세 개의 형상과 질량, 컨테이너 위치도 벤치마크용 합성 파라미터다. 트레이·목표 위치와 질량 배율은 [`configs/default.json`](../configs/default.json)에, 적재물별 원시 치수·질량과 마찰 설정은 [`src/rby1_tray/scene.py`](../src/rby1_tray/scene.py)에 기록했다.

## 손가락 접촉 프록시

Menagerie 원본 손가락 메시 두 개는 시각 형상으로 남겨 둔다. 충돌 계산에는 원본 손가락 메시를 끄고 각 손가락에 평평한 box 하나를 넣었다. 삼각 메시의 모서리가 손잡이에 걸리면서 파지가 불안정해지는 현상을 줄이고, 네 접촉면의 힘과 반대 방향 법선을 평가하기 위한 선택이다.

프록시는 손가락 로컬 좌표에서 중심 `(0, 0, -0.027) m`, 반치수 `(0.003, 0.014, 0.025) m`다. 전체 크기는 6×28×50 mm다. 원본의 접촉면 메시로 삼은 `EE_FINGER_0.obj`의 축 정렬 경계 상자는 3×32×60 mm다. 프록시와 원본 메시의 크기 비율은 x/y/z축에서 2.000/0.875/0.833이고, 경계 상자 중심 차이는 `(1.5, 0, 3.5) mm`다. 프록시는 y축 양쪽에서 2 mm씩, z축 끝에서 합계 10 mm 짧고, x축 두께는 3 mm 더 크다.

이 수치는 표면 간 거리나 체적 일치율이 아니라 OBJ 정점의 축 정렬 경계 상자 비교다. 프록시가 실제 고무 패드의 변형이나 마찰 분포를 재현한다는 근거로 쓰지 않는다. `upstream.json`의 `finger_proxy_comparison`에 실행 당시 측정값을 기록하고 테스트에서 장면 XML의 프록시 치수와 같은지 확인한다.

## 충돌 제외 범위

원본 A형 모델의 초기 자세에서는 베이스 메시와 `wheel_l`, `wheel_r`, `link_torso_0`가 겹친다. 고정 지그 실험에서 이 세 구조 인접 쌍만 collision exclusion에 추가했다. 원본에 있던 `base`와 `link_torso_1` 제외 등은 유지한다. 팔과 환경, 팔과 트레이 사이 충돌은 켜 둔다.

구조 인접 쌍을 제외했기 때문에 베이스 내부의 조립 간섭은 충돌 안전성 평가 대상이 아니다. 실행 중 금지 접촉 검사는 팔과 작업 환경 사이의 침투를 대상으로 한다.

## 재현과 해석

`python -m rby1_tray.cli fetch-assets`는 고정한 원본을 준비하고 무결성을 검사한다. 각 실행 폴더의 `upstream.json`에는 원격 저장소, 커밋, 깨끗한 작업 트리 여부, 파일 해시, 손가락 프록시 비교가 들어간다. `scene.xml`은 해당 실행에 사용한 최종 장면이다.

성공 결과는 이 합성 장면과 설정에서 트레이가 자유 강체로 움직이고, 네 손가락 접촉과 적재물 유지 조건을 통과했다는 뜻이다. 실물 적용에는 손잡이 치수 측정, 질량과 관성 추정, 액추에이터 식별, 센서 모델, 고정 지그 조건의 재검증이 더 필요하다.

## 수치 판정 규약

계획 단계의 금지 충돌 검사는 1 mm를 넘는 침투를 거부한다. 실행 단계에서는 접촉 법선 힘이 0.01 N을 넘고 침투가 2 mm를 넘는 금지 로봇 접촉을 실패로 기록한다. 지정 패드–손잡이 접촉과 베이스–바닥 접촉은 작업 규약에 따라 허용한다. 따라서 결과의 금지 접촉 판정은 이 수치 허용 범위를 포함한다.

각 패드에는 0.1 N 이상의 접촉력이 필요하고, 한 손의 두 패드가 미는 법선 사이 코사인이 -0.5 미만이어야 한다. 적재물 경계는 형상에서 구한 회전 불변 외접 구로 보수적으로 검사한다. 바닥판 지지에는 트레이 위쪽을 향하는 법선과 적재물 중심이 윗면 쪽에 있다는 조건을 함께 쓴다. 안착과 회수 후 유지에는 기울기 0.05 rad 이하, 트레이 선속도 0.03 m/s 이하, 각속도 0.1 rad/s 이하, 적재물 속도 0.05 m/s 이하를 적용한다. 기준값은 설정과 소스 해시로 실행별 보존한다.
