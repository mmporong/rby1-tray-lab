# 모델링 범위와 판정 규약

현재 기본 실행은 `configs/mobile-native.json`의 **RBY1-M 1.2 이동형 실험**이다. Menagerie 커밋 `cda5236f98383f6fbaa4820c6b18dba892cd087f`의 `rby1m_1.2.xml`을 사용한다. 원본 캐시를 수정하지 않으며 원격 URL·커밋·작업 트리·라이선스·XML과 메시 해시를 검사한다. 원본 라이선스는 Apache-2.0이다.

## 이동형 장면

- 베이스 자유 관절과 네 바퀴 구동기를 유지한다. 베이스 이동은 바퀴 속도 명령과 바닥 접촉으로 발생한다.
- 원본 바퀴에는 개별 메카넘 롤러 물리가 없다. 검증 범위는 종방향 이동과 정차이며 횡이동 성능을 포함하지 않는다.
- 휠 속도 루프 게인은 원본의 4000에서 100으로 조정한다. 강체 바퀴에서 출발·제동 충격을 줄이기 위한 시뮬레이션 튜닝값이다. 반경 0.076 m, 반트랙 0.245 m도 현 모델의 설계값이다.
- 트레이와 세 적재물은 각각 자유 관절·질량·관성·마찰·충돌 형상을 가진다. 실행 중 물체 부착, mocap 이동, 상태 덮어쓰기, 외력 운반을 사용하지 않는다.
- 트레이는 360×540 mm 바닥판과 테두리를 갖는다. 손잡이·파지용 돌출부·합성 손가락 패드를 추가하지 않는다. 원본 그리퍼 CAD·슬라이드 관절·동기화 제약 구조·힘 제한을 유지하고, 접촉은 아래의 CAD 충돌 교정을 적용한다.
- 1.20 m 지지면의 컨테이너는 바닥까지 이어지는 네 다리·가로대·데크에 연결된다. 지지 구조 전체가 충돌 계산에 참여한다.
- 카메라 케이스도 질량·충돌을 가진다. 마운트 TF와 케이스 관성은 설계 가정이다. 브래킷·배선·케이블 장력·패드 탄성은 별도 모델링하지 않았다.

## 기본 그리퍼와 CAD 충돌 교정

고정한 upstream XML의 `in-model-collision` 클래스는 type을 생략한다. MuJoCo에서 기본 geom type은 sphere이므로 `mesh=EE_FINGER_*`를 적어도 원본 기본 접촉은 반경 약 15 mm의 자동 피팅 구형이다. 시각 메시와 접촉 형상이 같은 것으로 간주하면 안 된다.

현재 기본 설정 `gripper_collision=cad_mesh`는 EE_BODY와 두 손가락 부품에 `type=mesh`를 명시한다. 원본 CAD의 convex hull로 접촉을 계산하며 파지용 box나 돌출 손잡이를 추가하지 않는다. 메시 원본·그리퍼 관절·구동기·마찰은 유지한다. 손가락 동기화 equality의 기본 20 ms 시간상수는 하중에서 두 finger joint가 6–7 mm 벌어지는 유연성을 만들었다. 이 실험은 `gripper_coupling_timeconst_s=0.004`를 명시해 기계적 동기화를 튜닝한다. 실측 강성 식별값이 아니며 물체를 부착하는 제약도 아니다. 이 교정은 충돌 형상이 upstream 기본값 그대로라는 뜻이 아니다. 팔·몸통·휠의 나머지 원본 충돌 근사와 제외는 유지하며 전체 CAD 정밀 충돌을 검증했다고 보고하지 않는다.

[MuJoCo geom type과 mesh primitive fitting 규칙](https://mujoco.readthedocs.io/en/stable/XMLreference.html#body-geom)을 따른다. 컴파일 후 손가락 geom type과 원본 메시 참조를 검사해 시각 형상과 접촉 형상을 혼동하는 회귀를 막는다.

## 센서와 평가의 경계

머리 RGB-D는 트레이 중심·방향을 추정하고, 손목 RGB-D는 파지점 주변을 관측한다. 베이스 추정은 네 바퀴 엔코더 오도메트리, 카메라 TF는 오도메트리와 관절 엔코더의 FK로 계산한다. 시뮬레이터의 자유 베이스 정답 TF는 제어용 카메라 패킷에 넣지 않는다.

F/T 센서는 손목과 그리퍼 사이의 고정 플랜지 경계에 둔다. 원본 EE 몸체와 손가락의 월드 형상을 유지하면서 경계 몸체 아래로 옮겼다. 센서는 이상적인 6축 반력·모멘트이며 실제 영점 드리프트·대역폭·분해능을 식별한 모델은 아니다.

`controller-data/`에는 영상·보정행렬·엔코더·손목 힘/토크·명령을 저장한다. `trace.jsonl`은 독립 평가용 물체 정답 위치·접촉까지 포함한다. 두 파일의 역할을 섞어 학습 입력이나 인식 성능으로 보고하면 안 된다. 하드웨어 근거와 좌표계는 [센서·전이 계약](sensors-and-transfer.md)에 정리한다.

## 운동 계획과 제어

출발·종료 기준은 고정 원본 모델의 `qpos0`다. 해당 XML에는 home 키프레임이 없으며, 기본값은 몸통·양팔 20관절과 헤드 2축이 0 rad, 그리퍼가 0 m인 자세다. 베이스 출발 위치는 작업장 설정의 `initial_pose_xy_yaw`를 따른다. 초기 기본 자세를 유지한 뒤 정차 상태에서 낮은 작업 자세로 전환한다. 안착·해제·손 회수 후에는 상체를 유지하며 출발 위치까지 휠 제어로 후진하고, 그곳에서 모델 기본 자세와 그리퍼로 복귀한다. 순간적인 상태 초기화로 원복하지 않는다.

기존 다섯 조건에 `returned_home`을 추가했다. 손 회수가 끝나도 평가를 종료하지 않으며, 복귀 중 트레이와 적재물의 지지·정지·손 해제를 계속 검사한다. 실제 관절·헤드·그리퍼·베이스 자세와 속도가 `mission_cycle.home_tolerances` 안에서 0.5초 유지돼야 전체 성공이다. 모델 기본 자세와 허용 오차는 제어 데이터의 `schema.json`에도 기록한다.

수치 IK는 몸통 6관절과 양팔 14관절을 함께 풀어 양손 TCP 위치·방향, 관절 한계, 중력 토크 여유, 금지 충돌을 검사한다. 운반 시 scratch IK 장면의 트레이는 인식 결과와 계획한 CAD 자세로 배치한다. 이 계획용 상태 변경은 물리를 적분하는 세션과 분리된다.

픽업 접근은 몸통을 낮게 유지한 채 양팔을 베이스와 적재물 바깥으로 이동시킨다. 파지 접근 중심보다 전방 50 mm·위쪽 110 mm인 팔 회피점을 거친 뒤 바닥 접근 자세로 이동한다. 높은 운반 자세는 마지막 IK의 수치 초기값으로만 사용하며 실행 관절 경유점에는 넣지 않는다. 실제 제어와 같은 C1 Hermite 경로를 구간당 51개 자세에서 금지 충돌로 검사하고, 곡선의 관절 한계는 극값까지 검사한다. 이산 사전 검사와 별도로 실제 실행의 충돌·접촉·적재물 상태는 2 ms 독립 평가기로 판정한다. 이 결과는 해당 설정의 시뮬레이션 검증이며 실물 경로 검증을 대신하지 않는다.

팔 구동은 힘 제한 위치 루프와 중력/속도 피드포워드, 베이스 구동은 오도메트리 피드백 속도 제어다. 몸통·양팔 위치/속도 게인은 `upper_body_servo`에 명시하며 원본 4000/400에서 2000/200으로 조정한 합성 튜닝 조건이다. 하드웨어 제어기 식별값이 아니다. 원본 관절 구동기 파라미터는 실측 식별값이 아니며 실물 SDK로 전송한 결과도 아니다. 물리·제어·평가는 2 ms, 요약 trace는 20 ms 주기다.

## 독립 판정

단계 이름만으로 성공하지 않는다. 평가기는 각 물리 스텝에서 아래를 확인하고 최초 실패를 보존한다.

1. 각 손가락은 해당 트레이 테두리에 접촉해야 한다. 대향 법선 코사인은 -0.5 미만, 각 패드 접촉력은 0.1 N 이상이어야 한다.
2. 안정 파지 뒤 트레이 바닥이 초기보다 30 mm 이상 상승해야 한다. 안착 전 파지 이탈은 실패다.
3. 세 적재물의 정체성과 트레이 내부 보존을 검사한다. 경계는 형상별 외접 구로 보수적으로 계산한다.
4. 트레이 전체 경계가 목표 내부에 들어가고 컨테이너 바닥에 지지돼야 한다. 바닥 높이 오차 6 mm 이하, 기울기 0.05 rad 이하, 선속도 0.03 m/s 이하, 각속도 0.1 rad/s 이하여야 한다.
5. 적재물 세 개가 트레이 위쪽 바닥판에 지지되고 각각 0.05 m/s 이하로 안정돼야 한다.
6. 모든 로봇–트레이 접촉이 사라지고 두 TCP가 파지점에서 80 mm 이상 떨어진 상태를 0.5초 유지해야 성공한다.

계획은 1 mm 초과 금지 침투를 거부한다. 실행은 법선 힘 0.01 N 이상·침투 2 mm 이상인 금지 접촉을 실패로 기록한다. M형에 새 팔–환경 충돌 제외를 추가하지 않는다. 지정 손가락–해당 테두리, 바퀴–바닥은 허용한다.

## 과거 고정 베이스 기록

`configs/default.json`과 `evidence/demo`, `evidence/dataset`, `evidence/ablations`는 **과거 A형 고정 지그 실험**이다. 그 실험에는 합성 손잡이와 flat-pad 프록시가 있었고 정답 상태를 사용했다. 기존 0.75 m 성공률을 현재 기본 그리퍼·RGB-D·이동형 실험의 성과로 합산하지 않는다. 과거 manifest의 소스 해시는 기록된 Git 커밋에서 검증한다.
